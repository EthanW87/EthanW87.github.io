Project Overview & Leadership

The SAE AutoDrive Challenge II tasks university teams with converting a stock vehicle into a fully autonomous Level 4 driving platform. As a key contributor to the Queen's AutoDrive team, I co-engineered safety-critical software modules and co-authored our competition proposal, securing 2nd Place in the SAE Mobility Innovation Award category.

Key Technical Contributions

  • Embedded Watchdog Systems: Developed custom C++ memory monitoring and node health watchdogs to ensure real-time fault isolation within the ROS2 architecture.
  • Mobility Innovation Pitch: Co-authored technical documentation and presented system safety architectures to industry judges.
  • On-Site Diagnostics: Supported paddock hardware calibration, sensor alignment, and drive-by-wire integration tests during competition testing days.
